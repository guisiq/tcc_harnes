# Citações acadêmicas da ficha tema

Esta pasta reúne a fundamentação acadêmica usada para sustentar as afirmações verificáveis de `ficha_tema_tcc.md`.

As fontes foram localizadas por busca semântica no SciSpace. As notas abaixo distinguem: (a) evidência direta; (b) evidência relacionada/indireta; e (c) lacunas que ainda precisam de revisão focal.

Em 2026-11-06, as notas sobre memória e a ordem de leitura foram alinhadas à [bibliografia auditada](../../../../TCC_Checkpoint_JSON_Obsidian/06_Referencias/referencias.md). O recorte vigente está no [vault principal](../../../../TCC_Checkpoint_JSON_Obsidian/01_Projeto/01_visao_geral.md): writers compactos sob GU-json fixo. Fontes do acervo antigo fora das 19 entradas auditadas não foram automaticamente revalidadas, importadas no Zotero ou incorporadas ao experimento.

## Regra de uso na ficha

Cada afirmação empírica ou sobre o estado da literatura recebe ao menos um link para uma destas notas. Definições operacionais, decisões metodológicas e hipóteses do próprio TCC são identificadas como proposições do estudo e não como fatos já demonstrados.

Quando pertinente, usar duas fontes complementares, por exemplo Hwang + PRISM para mecanismos de atualização, e MemoryAgentBench + LongMemEval para atualização de conhecimento. Explicitar diferenças de tarefa e métrica; duas citações indiretas não tornam uma afirmação evidência direta.
