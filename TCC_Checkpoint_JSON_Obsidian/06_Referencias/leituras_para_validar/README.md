# Notas de leitura para validação pessoal

Estas notas foram transferidas de um vault de rascunho para concentrar o material de referência. Use-as como roteiro para conferir as fontes originais, não como afirmações já validadas. Algumas registram decisões de versões anteriores; o [artigo atual](../../07_Artigo_TCC/artigo_tcc_unitins.md) e a [ficha do tema](../../01_Projeto/04_ficha_tema.md) definem o recorte vigente.

As fontes foram reunidas por busca bibliográfica e não foram todas verificadas integralmente nem importadas para o Zotero. Diferencie evidência direta, evidência indireta e questão ainda em aberto; uma nota de leitura não substitui a fonte primária.
