# Como usar este vault no Obsidian

Este pacote foi preparado como um **vault Obsidian portátil**.

## Abrir

1. Extraia o arquivo `.zip`.
2. Abra o Obsidian.
3. Escolha **Open folder as vault / Abrir pasta como cofre**.
4. Selecione a pasta `TCC_Checkpoint_JSON_Obsidian`.
5. Comece por [[00_INDEX|00_INDEX]].

## Recursos usados

- links internos no formato de wikilinks do Obsidian;
- aliases no YAML frontmatter;
- tags por área;
- navegação por pastas;
- links externos normais em Markdown;
- páginas MOC/índice para navegação e Graph View.

## Graph View

As ligações entre notas foram preservadas como wikilinks.  
Isso permite visualizar relações entre:

- projeto;
- metodologia;
- literatura;
- implementação;
- planejamento;
- referências.

## Sugestão de plugins nativos

Não são obrigatórios, mas ajudam:

- Backlinks;
- Graph View;
- Properties View;
- Search;
- Tags;
- Templates.

## Convenção

Arquivos `00_...` funcionam como índices/MOCs.  
Os demais seguem numeração por seção para manter ordem previsível no explorador de arquivos.

## Observação sobre links externos

URLs de artigos, modelos e datasets foram mantidas como hyperlinks normais para permanecerem clicáveis fora do Obsidian também.
