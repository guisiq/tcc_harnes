# Como usar este vault no Obsidian

Abra a pasta `TCC_Checkpoint_JSON_Obsidian` como um vault no Obsidian. Comece pelo [índice do projeto](00_INDEX.md).

O [artigo em Markdown](07_Artigo_TCC/artigo_tcc_unitins.md) é a fonte de verdade para o escopo e o método. A [ficha do tema](01_Projeto/04_ficha_tema.md) resume a delimitação e lista questões para conferência. Notas de implementação e leitura são complementares; confira as fontes antes de incorporar suas afirmações ao artigo.

As referências bibliográficas e os PDFs dos artigos permanecem no repositório, separados das notas de trabalho.
